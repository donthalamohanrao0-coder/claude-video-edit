# 1019 — premium edit pipeline

Source: `1019.mov` from release [v1](https://github.com/donthalamohanrao0-coder/claude-video-edit/releases/tag/v1) (Telugu n8n course intro, 2:25, 1080p60 HEVC).
Output: `1019_edited.mp4` (1080p60 H.264, AAC 48 kHz, -14 LUFS).

Follows the skills in `skills/`: cut-video (tighten pauses), add-zooms (punch-ins / push-ins),
remotion-video-skill + video-shotcraft (motion graphics), clean-audio (least processing), suggest-sfx (function-first SFX, cue sheet, audibility check).

## Steps

| # | Step | Command | Output |
|---|---|---|---|
| 1 | Transcribe (Sarvam `saarika:v2.5`, `te-IN`, one request per pause-delimited phrase) | `SARVAM_API_KEY=... python3 sarvam_phrases.py voice16k.wav sil.txt out.json` | `transcript_te.json` (tech terms corrected by hand: n8n, AI, Nodes, APIs, RAG, MCP, Claude) |
| 2 | Master cut: tighten 13 pauses ≥0.36 s to 0.24 s, trim head/tail, light grade, gentle voice cleanup | `python3 make_master.py 1019.mov <dir>` | `master.mp4` (no audio), `voice.wav`, `cutmap.json` |
| 3 | Map transcript to the master timeline | `python3 remap_transcript.py transcript_te.json cutmap.json ../remotion/src/data/transcript.json` | word-time estimates |
| 4 | Motion graphics + zooms + English captions (Remotion) | `cd ../remotion && cp <dir>/master.mp4 public/ && npx remotion render Edit1019 video.mp4 --muted` | `video.mp4` |
| 5 | SFX library, cue sheet, mix | `python3 sfx/gen_sfx.py ../sfx` · `python3 sfx/build_plan.py ../remotion/src/data/cues.json sfx/sfx-plan.json` · `python3 sfx/mix_sfx.py sfx/sfx-plan.json ../sfx voice.wav final.wav` | `final.wav` |
| 6 | Check SFX levels | `python3 sfx/check_audibility.py sfx/sfx-plan.json sfxbus.wav voice.wav <voice gain>` | momentary SFX/voice ratio per cue |
| 7 | Assemble | `./assemble.sh video.mp4 final.wav ../1019_edited.mp4` | final MP4 |

## Where to change things

- **Timing of every graphic and sound:** `remotion/src/data/cues.json` (master-timeline seconds). Re-run `build_plan.py` after editing so SFX follow.
- **Caption lines (English, key moments only):** `remotion/src/components/Captions.tsx` → `LINES`.
- **Graphics / copy:** `remotion/src/components/Overlays.tsx`; colours and fonts in `remotion/src/theme.ts` (n8n coral `#EA4B71` on a light theme, Poppins).
- **Zoom behaviour:** `remotion/src/components/Camera.tsx` (`cuts` + `switches` alternate framing, `punches`, `whips`).
- **SFX gains:** `G` in `_work/sfx/build_plan.py`. Count-up ticks are `optional` (`mix_sfx.py --no-optional` drops them).
- Preview in the browser: `cd remotion && npm i && npm run studio`.
